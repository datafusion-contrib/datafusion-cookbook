# PostgreSQL connector

Query tables that live in a PostgreSQL database from DataFusion SQL,
using
[datafusion-table-providers](https://github.com/datafusion-contrib/datafusion-table-providers)
to expose remote Postgres tables as DataFusion tables (with predicate
pushdown where supported).
