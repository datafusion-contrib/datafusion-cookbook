# Variant

Store and query semi-structured (JSON-like) data using the
[Variant binary format](https://github.com/apache/parquet-format/blob/master/VariantEncoding.md),
which stores JSON-like values in a compact binary encoding that supports
shredding and is much faster to query than parsing JSON text.
