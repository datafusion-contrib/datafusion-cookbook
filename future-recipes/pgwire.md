# Postgres wire protocol

Expose a DataFusion engine over the PostgreSQL wire protocol (e.g. via
the [pgwire](https://github.com/sunng87/pgwire) crate) so any Postgres
client — `psql`, drivers, BI tools — can connect and run queries
without knowing DataFusion is behind it.
