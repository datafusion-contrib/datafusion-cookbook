# Arrow version conversion

Convert record batches and arrow arrays between different arrow versions, 
for example to read arrays written with `arrow` 57 in `arrow` 59.

This uses arrow's CData interface and the fact that the arrow in memory format
it self does not change between versions of the arrow library.
